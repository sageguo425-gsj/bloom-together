# 音频文件说明

请将以下音频文件放置在此目录：

1. `rain-on-leaves.mp3` - 雨打树叶声
2. `temple-bell.mp3` - 寺庙钟声
3. `campfire.mp3` - 篝火声
4. `snow-steps.mp3` - 踩雪声

## 文件要求

- 格式：MP3 或 WAV
- 时长：建议 30 秒以上
- 音质：128kbps 或更高
- 大小：单个文件不超过 5MB

## 获取音频

你可以从以下网站获取免费白噪音音频：

- Freesound.org
- Zapsplat.com
- BBC Sound Effects

或者使用你已经下载好的音频文件。

## 注意事项

如果音频文件名不同，请修改 `lib/types/whiteNoise.ts` 中的 `audioPath` 配置。
