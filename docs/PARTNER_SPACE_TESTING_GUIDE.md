# 伴侣空间功能测试指南

## 准备工作

### 创建测试账号

1. **账号A（主账号）**
   - 邮箱：your-email@example.com
   - 用户名：用户A

2. **账号B（伴侣账号）**
   - 邮箱：partner-email@example.com
   - 用户名：用户B

## 测试场景 1：发送和接受邀请

### 步骤 1：账号A发送邀请

1. 用账号A登录
2. 访问 http://localhost:3000/dashboard/partner
3. 应该看到"伴侣空间"邀请页面
4. 在邮箱输入框中输入账号B的邮箱
5. 点击"发送邀请"按钮
6. 应该看到成功提示
7. 在"发送的邀请"列表中看到刚发送的邀请（状态：等待中）

### 步骤 2：账号B接受邀请

1. 退出账号A
2. 用账号B登录
3. 访问 http://localhost:3000/dashboard/partner
4. 在"收到的邀请"列表中应该看到账号A发送的邀请
5. 邀请卡片显示：
   - 发送者头像/首字母
   - 发送者用户名
   - 发送者邮箱
   - 发送时间
   - 状态标签（黄色"等待中"）
6. 点击"接受"按钮
7. 页面应该自动刷新

### 步骤 3：验证绑定成功

**账号B的视角：**
1. 刷新后应该看到伴侣空间主界面
2. 右侧"连接状态"卡片显示：
   - 账号A的头像/首字母
   - 账号A的用户名和邮箱
   - 等级和经验值
   - 绿色脉冲点（在线状态）
   - "已连接"标签

**账号A的视角：**
1. 刷新页面
2. 应该也能看到伴侣空间主界面
3. 显示账号B的信息

## 测试场景 2：拒绝邀请

### 步骤：

1. 账号A发送邀请给账号B
2. 账号B登录，看到邀请
3. 点击"拒绝"按钮
4. 邀请状态变为"已拒绝"（红色标签）
5. 账号A刷新页面，在"发送的邀请"中看到状态变为"已拒绝"

## 测试场景 3：取消邀请

### 步骤：

1. 账号A发送邀请给账号B
2. 在"发送的邀请"列表中找到该邀请
3. 点击"取消"按钮
4. 邀请状态变为"已取消"（灰色标签）
5. 账号B登录，该邀请状态显示为"已取消"

## 测试场景 4：解除伴侣关系

### 步骤：

1. 确保账号A和账号B已绑定
2. 用账号A登录
3. 访问伴侣空间页面
4. 在"连接状态"卡片中点击"解除伴侣关系"按钮
5. 确认对话框中点击"确定"
6. 页面刷新，返回到邀请页面
7. 账号B刷新页面，也应该返回到邀请页面

## 测试场景 5：查看伴侣的任务和习惯

### 前提：账号A和账号B已绑定

### 步骤：

1. **账号B创建共享内容**
   - 创建一个任务，勾选"共享给伴侣"
   - 创建一个习惯，勾选"共享给伴侣"
   - 创建一个项目，勾选"共享给伴侣"

2. **账号A查看**
   - 访问伴侣空间页面
   - 应该能看到账号B的：
     - 今日任务列表
     - 习惯打卡情况
     - 项目进度

3. **点赞功能**
   - 点击任务/习惯/项目的点赞按钮
   - 点赞数应该增加
   - 再次点击可以取消点赞

## 测试场景 6：留言板

### 步骤：

1. 账号A在留言板输入消息
2. 点击发送
3. 消息出现在留言板中
4. 账号B刷新页面
5. 应该能看到账号A发送的消息
6. 账号B回复消息
7. 账号A刷新页面，看到回复

## 测试场景 7：共同目标

### 步骤：

1. 账号A创建共同目标
2. 设置目标类型、目标值、开始和结束日期
3. 账号B刷新页面，看到共同目标
4. 双方都可以更新进度
5. 进度条显示双方的贡献

## 常见问题排查

### 问题 1：发送邀请后没有显示在列表中

**检查：**
- 刷新页面
- 检查浏览器控制台是否有错误
- 检查数据库 `partner_invitations` 表

### 问题 2：接受邀请后页面没有变化

**检查：**
- 手动刷新页面（F5）
- 检查浏览器控制台错误
- 检查数据库 `users` 表的 `partner_id` 字段

### 问题 3：看不到伴侣的任务/习惯

**检查：**
- 确认内容是否勾选了"共享给伴侣"
- 检查 `is_shared` 字段是否为 `true`
- 检查 RLS 策略是否正确

### 问题 4：连接状态显示"未连接"

**检查：**
- 数据库中 `users` 表的 `partner_id` 是否正确设置
- 刷新页面
- 重新登录

## 数据库验证

### 检查邀请记录

```sql
SELECT * FROM partner_invitations 
ORDER BY created_at DESC;
```

### 检查伴侣绑定

```sql
SELECT id, email, username, partner_id 
FROM users 
WHERE partner_id IS NOT NULL;
```

### 检查共享内容

```sql
-- 共享的任务
SELECT * FROM tasks WHERE is_shared = true;

-- 共享的习惯
SELECT * FROM habits WHERE is_shared = true;

-- 共享的项目
SELECT * FROM projects WHERE is_shared = true;
```
