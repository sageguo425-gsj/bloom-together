# 白噪音功能使用指南

## 功能概览

番茄钟页面集成了白噪音播放功能，帮助用户在专注工作时营造更好的环境氛围。

### 主要特性

- ✅ 同时播放多个白噪音混合
- ✅ 独立调节每个白噪音的音量
- ✅ 保存自定义混音方案
- ✅ 快速加载已保存方案
- ✅ 手机锁屏后继续播放
- ✅ 切换到其他 APP 继续播放
- ✅ 循环播放，无缝衔接

## 音频文件设置

### 文件位置

请将白噪音音频文件放置在以下目录：

```
planning-app/public/sounds/
```

### 所需文件

创建 `public/sounds/` 目录并放置以下音频文件：

1. **雨打树叶** - `rain-on-leaves.mp3`
2. **寺庙钟声** - `temple-bell.mp3`
3. **篝火声** - `campfire.mp3`
4. **踩雪声** - `snow-steps.mp3`

### 音频文件要求

- **格式**: MP3（推荐）或 WAV
- **时长**: 建议 30 秒以上，以便循环播放时更自然
- **音质**: 建议 128kbps 或更高
- **文件大小**: 建议单个文件不超过 5MB

### 获取音频文件

你可以从以下来源获取白噪音音频：

1. **免费资源**:
   - [Freesound](https://freesound.org/) - 免费音效库
   - [Zapsplat](https://www.zapsplat.com/) - 免费音效
   - [BBC Sound Effects](https://sound-effects.bbcrewind.co.uk/) - BBC 音效库

2. **付费资源**:
   - [AudioJungle](https://audiojungle.net/)
   - [Epidemic Sound](https://www.epidemicsound.com/)

3. **自己录制**:
   - 使用手机或录音设备录制真实环境音

### 文件命名规范

如果你想添加更多白噪音，请按照以下步骤：

1. 将音频文件放入 `public/sounds/` 目录
2. 更新 `lib/types/whiteNoise.ts` 文件中的 `WHITE_NOISES` 数组

```typescript
export const WHITE_NOISES: WhiteNoise[] = [
  // ... 现有的白噪音
  {
    id: 'ocean',  // 唯一标识符
    name: '海浪声',  // 显示名称
    icon: '🌊',  // emoji 图标
    audioPath: '/sounds/ocean-waves.mp3',  // 音频文件路径
    color: 'from-blue-400 to-cyan-500',  // 渐变色
  },
];
```

## 使用方法

### 基本操作

1. **播放白噪音**
   - 点击白噪音卡片中央的图标即可播放/暂停
   - 播放时卡片会显示渐变色背景

2. **调节音量**
   - 拖动卡片底部的滑块调节音量
   - 音量范围：0% - 100%

3. **混合播放**
   - 可以同时播放多个白噪音
   - 每个白噪音独立控制音量
   - 创造你自己的专属混音

4. **保存方案**
   - 点击右上角"保存方案"按钮
   - 输入方案名称（如"雨天工作"、"深夜学习"）
   - 当前播放的所有白噪音及其音量会被保存

5. **加载方案**
   - 在"已保存的方案"列表中点击方案名称
   - 自动加载该方案的所有设置并开始播放

6. **停止全部**
   - 点击右上角"停止全部"按钮
   - 停止所有正在播放的白噪音

### 后台播放

白噪音支持后台播放，即使：
- 手机锁屏
- 切换到其他 APP
- 浏览器标签页切换到后台

音频会继续播放，不会中断。

#### 1. 雨天专注

#### 2. 冬日宁静

#### 3. 禅意冥想

#### 4. 温暖夜晚

## 技术实现

### 核心技术

- **HTML5 Audio API**: 音频播放和控制
- **循环播放**: `audio.loop = true`
- **音量控制**: `audio.volume = 0.5`
- **多音频混合**: 同时创建多个 Audio 实例

### 数据存储

混音方案保存在 Supabase 数据库中：

```sql
CREATE TABLE white_noise_mixes (
  id UUID PRIMARY KEY,
  user_id UUID REFERENCES auth.users(id),
  name TEXT NOT NULL,
  sounds JSONB NOT NULL,  -- [{ soundId, volume }]
  created_at TIMESTAMP
);
```

### 自定义 Hook

`useWhiteNoise` Hook 提供了完整的白噪音控制功能：

```typescript
const {
  audioStates,      // 所有音频的状态
  initAudio,        // 初始化音频
  togglePlay,       // 切换播放/暂停
  setVolume,        // 设置音量
  stopAll,          // 停止所有
  getCurrentMix,    // 获取当前混音
  loadMix,          // 加载混音方案
} = useWhiteNoise();
```

## 故障排除

### 音频无法播放

1. **检查文件路径**
   - 确认音频文件在 `public/sounds/` 目录
   - 检查文件名是否正确

2. **检查浏览器控制台**
   - 打开开发者工具查看错误信息
   - 常见错误：404 Not Found（文件不存在）

3. **检查音频格式**
   - 确保使用 MP3 或 WAV 格式
   - 某些浏览器可能不支持特定编码

### 后台播放不工作

1. **iOS Safari**
   - 需要用户交互后才能播放
   - 建议添加到主屏幕使用

2. **Android Chrome**
   - 检查浏览器设置中的"后台播放"权限
   - 某些省电模式可能限制后台音频

### 音量调节无效

1. 检查系统音量是否静音
2. 检查浏览器标签页是否被静音
3. 尝试刷新页面重新加载

## 性能优化

### 内存管理

- 音频对象在组件卸载时自动清理
- 使用 `useRef` 避免重复创建 Audio 实例

### 加载优化

- 音频文件按需加载
- 首次点击时才开始加载音频

### 网络优化

- 建议使用 CDN 托管音频文件
- 压缩音频文件减小体积
