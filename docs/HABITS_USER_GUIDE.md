# 习惯养成模块使用指南

## 功能概述

习惯养成模块帮助你培养良好习惯，通过每日打卡、连续记录和成就激励，让你坚持养成好习惯。

## 主要功能

### 1. 创建习惯

点击"+ 新建习惯"按钮，填写以下信息：

#### 基础信息
- **习惯名称**：例如"每天阅读30分钟"
- **习惯描述**：描述这个习惯的目的和意义
- **图标选择**：从12个预设图标中选择（🏃📚💧🧘🎯💪🎨🎵✍️🌱☕🛏️）
- **颜色选择**：从8种颜色中选择，用于区分不同习惯

#### 频率设置
- **每天**：每天需要打卡的次数（1-10次）
- **每周**：每周需要打卡的次数（1-7次）
- **每月**：每月需要打卡的次数（1-31次）

#### 目标设置
- **连续打卡目标**：设定连续打卡天数目标（默认30天）
- **总打卡目标**：设定总打卡次数目标（默认100次）

### 2. 打卡功能

#### 一键打卡
1. 在习惯卡片上点击"✓ 今日打卡"按钮
2. 在弹出的确认对话框中可以添加备注
3. 点击"确认打卡"完成打卡
4. 显示打卡成功动画

#### 打卡规则
- 每个习惯每天只能打卡一次
- 已打卡的习惯按钮显示为"✓ 已打卡"（灰色）
- 打卡后自动更新连续打卡天数

#### 连续打卡计算
- **连续打卡**：如果昨天打卡了，今天打卡后连续天数+1
- **断链**：如果昨天没打卡，今天打卡后连续天数重置为1
- **最长记录**：自动记录你的最长连续打卡天数

### 3. 习惯展示

#### 卡片视图
每个习惯卡片显示：
- 习惯名称和图标
- 频率要求（每天/周/月几次）
- 🔥 连续打卡天数（当前/最长）
- 本周打卡情况（7天预览）
  - ✓ = 已打卡（绿色）
  - ○ = 未打卡（灰色）
- 成就里程碑徽章
  - 🌱 7天 - 坚持一周
  - 🌿 30天 - 坚持一月
  - 🌳 100天 - 百日坚持
  - 🏆 365天 - 坚持一年
- 今日打卡按钮
- 📅 日历按钮

#### 日历视图
切换到日历视图可以：
- 查看整月的打卡历史
- 绿色日期 = 已打卡
- 灰色日期 = 未打卡
- 蓝色圆圈 = 今天
- 点击日期查看当天打卡详情（时间、备注）

### 4. 习惯链

#### 连续打卡激励
- 显示当前连续打卡天数（🔥 火焰图标）
- 显示最长连续打卡记录
- 达到里程碑时显示成就徽章

#### 断链提醒
- 如果连续打卡中断，连续天数会重置为1
- 鼓励你重新开始，继续坚持

### 5. 成就系统

#### 里程碑徽章
- **🌱 7天**：坚持一周 - 习惯初步养成
- **🌿 30天**：坚持一月 - 习惯基本稳定
- **🌳 100天**：百日坚持 - 习惯深度养成
- **🏆 365天**：坚持一年 - 习惯完全内化

#### 徽章显示
- 已达成：彩色显示，带边框
- 未达成：灰色显示，半透明

### 6. 统计数据

每个习惯卡片显示：
- **当前连续天数**：🔥 X 天
- **最长记录**：X 天
- **本周打卡**：7天的打卡情况可视化
- **总打卡次数**：累计打卡次数

## 常见问题

### Q: 今天已经打卡了，还能再打卡吗？
A: 不能。每个习惯每天只能打卡一次，以保证数据的准确性。

### Q: 如果忘记打卡了怎么办？
A: 连续打卡天数会重置为1，但不影响总打卡次数。重新开始坚持即可。

### Q: 可以修改已经打卡的记录吗？
A: 目前不支持修改历史打卡记录，请确保打卡时填写正确的信息。

### Q: 如何删除一个习惯？
A: 点击习惯卡片右上角的删除按钮（垃圾桶图标），确认后即可删除。

### Q: 习惯被删除后数据还能恢复吗？
A: 删除后习惯会被标记为不活跃，数据仍保留在数据库中，但前端不再显示。

## 技术说明

### 数据存储
- 习惯数据存储在 `habits` 表
- 打卡记录存储在 `habit_checkins` 表
- 使用 Supabase 实时数据库

### 安全性
- 启用行级安全策略（RLS）
- 用户只能访问自己的数据
- 所有操作需要身份验证

### 性能优化
- 使用索引优化查询
- 本周数据缓存
- 按需加载日历数据
