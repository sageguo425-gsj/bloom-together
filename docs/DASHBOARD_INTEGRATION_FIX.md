# 首页联动功能修复文档

## 修复概述

修复了首页与各功能页面之间的联动问题，使首页能够实时显示用户数据并提供快捷跳转。

## 修复的问题

### 1. ❌ 原问题：习惯打卡数据不更新
**现象**：用户在习惯页面打卡后，首页的习惯统计仍显示 0/0

**原因**：首页没有加载习惯数据

**解决方案**：
- 添加 `loadHabitStats()` 函数从数据库加载习惯统计
- 统计今日打卡数量和总习惯数量
- 在页面加载时自动获取数据

### 2. ❌ 原问题：创建任务按钮无响应
**现象**：点击"创建任务"按钮没有任何反应

**原因**：按钮是静态的 `<button>` 标签，没有跳转功能

**解决方案**：
- 将按钮改为 `<Link>` 组件
- 链接到 `/dashboard/tasks` 页面
- 保持原有样式和悬停效果

### 3. ❌ 原问题：开始专注按钮无响应
**现象**：点击"开始专注"按钮没有任何反应

**原因**：按钮是静态的 `<button>` 标签，没有跳转功能

**解决方案**：
- 将按钮改为 `<Link>` 组件
- 链接到 `/dashboard/pomodoro` 页面
- 保持原有样式和悬停效果

### 4. ❌ 原问题：统计卡片不可点击
**现象**：统计卡片看起来可以点击，但实际无法跳转

**原因**：卡片是 `<div>` 元素，没有链接功能

**解决方案**：
- 将所有统计卡片改为 `<Link>` 组件
- 添加对应的跳转链接：
  - 今日任务 → `/dashboard/tasks`
  - 专注时长 → `/dashboard/pomodoro`
  - 习惯打卡 → `/dashboard/habits`
  - 活跃项目 → `/dashboard/projects`

## 新增功能

### 1. 实时数据加载

**习惯统计**：
```typescript
interface HabitStats {
  totalHabits: number;      // 总习惯数
  checkedToday: number;     // 今日打卡数
  currentStreak: number;    // 连续天数（暂时为0）
}
```

**项目统计**：
```typescript
interface ProjectStats {
  activeProjects: number;   // 活跃项目数
}
```

### 2. 数据加载函数

**loadHabitStats(userId)**
- 查询用户的所有习惯
- 查询今日的打卡记录
- 计算统计数据并更新状态

**loadProjectStats(userId)**
- 查询状态为 'active' 的项目
- 统计活跃项目数量

### 3. 页面加载优化

使用 `Promise.all()` 并行加载所有数据：
```typescript
await Promise.all([
  loadTodayTasks(user.id),
  loadHabitStats(user.id),
  loadProjectStats(user.id)
]);
```

## 已知限制

1. **连续天数计算**：当前 `currentStreak` 固定为 0，需要实现连续打卡天数的计算逻辑
2. **专注时长统计**：当前固定显示 0h，需要从番茄钟记录中统计今日专注时长
3. **自动刷新**：数据不会自动刷新，需要手动刷新页面或重新进入
