# 伴侣空间功能使用指南

## 功能概述

伴侣空间是一个双人规划和互动功能，让你和伴侣可以互相查看规划、鼓励支持，共同成长。

## 部署步骤

### 1. 数据库配置

在 Supabase SQL Editor 中依次运行以下 SQL 文件：

```bash
# 1. 首先确保基础表已创建
database/schema.sql

# 2. 然后创建伴侣空间相关表
database/partner_space_schema.sql
```

### 2. 环境变量

确保 `.env.local` 文件中配置了 Supabase 连接信息：

```env
NEXT_PUBLIC_SUPABASE_URL=your_supabase_project_url
NEXT_PUBLIC_SUPABASE_ANON_KEY=your_supabase_anon_key
NEXT_PUBLIC_APP_URL=https://your-domain.vercel.app
```

### 3. 部署到 Vercel

```bash
cd planning-app
vercel --prod
```

## 功能说明

### 1. 伴侣配对

**邀请伴侣：**
- 进入"伴侣空间"页面
- 输入伴侣的邮箱地址
- 点击"发送邀请"
- 等待对方接受邀请

**接受邀请：**
- 收到邀请邮件后登录系统
- 在通知中心查看邀请
- 点击"接受"完成配对

### 2. 查看伴侣规划

**今日任务：**
- 查看伴侣今天的任务列表
- 查看任务完成情况
- 给任务点赞鼓励
- 只能查看，不能修改

**习惯打卡：**
- 查看伴侣的习惯列表
- 查看打卡进度和连续天数
- 查看本月打卡统计
- 给打卡点赞

**项目进度：**
- 查看伴侣的项目列表
- 查看项目进度百分比
- 查看项目详情（仅限共享项目）

### 3. 互动功能

**点赞鼓励：**
- 点击任务、习惯旁的爱心图标
- 点赞后伴侣会收到通知
- 可以取消点赞

**留言板：**
- 双人留言交流
- 支持表情符号
- 实时消息提醒
- 查看历史消息

**共同目标：**
- 创建双人共同目标
- 设置目标类型（任务/习惯/项目）
- 设置目标值和截止日期
- 双方共同完成进度
- 实时查看完成情况

### 4. 隐私设置

**共享设置：**
- 在创建/编辑任务时，勾选"共享给伴侣"
- 在创建/编辑习惯时，勾选"共享给伴侣"
- 在创建/编辑项目时，勾选"共享给伴侣"
- 未共享的内容对伴侣完全不可见

**解除配对：**
- 进入个人设置
- 点击"解除伴侣关系"
- 确认后双方配对关系解除
- 历史数据保留，但无法再互相查看

## 数据库表结构

### partner_invitations（伴侣邀请表）
- 存储邀请记录
- 状态：pending（待处理）、accepted（已接受）、rejected（已拒绝）、cancelled（已取消）

### likes（点赞表）
- 支持对任务、习惯打卡、项目点赞
- 每个用户对同一内容只能点赞一次

### messages（留言板表）
- 双人留言记录
- 支持文本和表情符号
- 已读/未读状态

### shared_goals（共同目标表）
- 双人共同目标
- 目标类型：project（项目）、habit（习惯）、task（任务）
- 状态：active（进行中）、completed（已完成）、cancelled（已取消）

### shared_goal_progress（共同目标进度表）
- 记录每次进度更新
- 关联到具体用户
- 可添加备注

### notifications（通知表）
- 点赞通知
- 留言通知
- 邀请通知
- 共同目标通知

## 安全性

### 行级安全策略（RLS）

所有表都启用了 RLS，确保：
- 用户只能查看自己和伴侣的数据
- 只能查看伴侣共享的内容
- 不能修改伴侣的数据
- 不能查看其他用户的数据

### 数据隔离

- 使用 Supabase RLS 策略实现数据隔离
- 前端和后端双重验证
- 敏感操作需要用户确认

## 常见问题

**Q: 如何取消已发送的邀请？**
A: 在邀请列表中找到对应邀请，点击"取消"按钮。

**Q: 伴侣看不到我的任务？**
A: 检查任务是否勾选了"共享给伴侣"选项。

**Q: 如何删除留言？**
A: 目前不支持删除留言，请谨慎发送。

**Q: 共同目标如何更新进度？**
A: 点击共同目标卡片，输入本次完成的数量，系统会自动累加。

**Q: 解除配对后数据会丢失吗？**
A: 不会，所有数据都会保留，只是无法再互相查看。
